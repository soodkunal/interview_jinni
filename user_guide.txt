INTERVIEW JINNI USER GUIDE

1. Introduction
Welcome to Interview Jinni, your AI-powered peer-to-peer platform designed to help you prepare for job interviews through skill analysis, automated scoring, and live practice.

2. Getting Started
2.1 Access and Login
Access: Open the application on your web browser (or mobile browser).

Login: Click the "Sign in with Google" button. The application uses your Google account for registration and profile picture fetching.

2.2 Finding Your User ID
Your User ID is a unique numeric identifier required for the Peer-to-Peer Search function.

Navigate to the My Profile page from the main dashboard.

Your User ID will be displayed prominently under your name. Share this ID with peers you wish to call directly.

3. Core Modules and Features
A. Profile & Skills Management (My Profile)
Goal: Define your current skill set to enable the Career Path Analysis.

Action: On the My Profile page, use the "Add Skill" input field to list your proficiency (e.g., React, Python, SQL). You can delete any skill listed.

B. Career Path Analysis
Goal: Identify skill gaps required for a target job role and receive learning resources.

Action (Skill Gap Analysis):

Select a job title from the Dropdown List (e.g., "Software Engineer").

OR Type a Custom Job Title (e.g., "AI Ethicist") into the input box.

Click "Analyze Skill Gap."

Result: The system compares the required skills (using database data, refined by AI, or fully AI-generated) against your profile and displays a list of missing skills, along with recommended learning resources (courses, documentation, etc.).

C. Mock Interview Practice
Goal: Practice answering questions and receive immediate, automated AI scoring.

Action:

Select a Job Role (or type a Custom Job Title).

Click "Generate Interview Questions." The system will provide 5 mixed (Technical, Behavioral, Situational) questions.

Choose Input Type: Select Audio (to record your voice) or Text (to type your answers).

Audio Mode: Click "Start Recording." Answer all questions, then click "Stop Recording."

Submission: The system will upload your answers and immediately enter the Analyzing... state.

Result: The page will update to show an Overall Score (1-10) and Detailed Feedback for each question, based on the Gemini API analysis.

4. Peer-to-Peer Call System (Live Hub)
The Live Hub facilitates real-time practice and doubt clearing with other users.

4.1 Setting Availability
Click the "Offline" button in the top right of the Live Hub page. It will toggle to "● Available." You must be available to receive calls.

4.2 Making a Call
You can initiate a call in two ways:

Available Peers: Find the user in the main list and click "Request Call."

Search by ID: Enter a known User ID into the search box and click "Search."

Note: You can only call users who are currently marked as "Available."

4.3 Call Status and Cooldown
If the recipient rejects the call, the button for that user will be disabled and marked "On Cooldown" for 2 minutes to prevent spam.

If the recipient accepts, both users are redirected to the live video call screen (WebRTC).

To end the call, click the "Hang Up" button.

5. Peer Review Hub
Goal: Provide feedback to peers and review your past scores.

Action (Request Review): On your My Sessions page, select a completed session and click "Request Peer Review." This adds your session to the public Hub.

Action (Submit Review): On the Review Hub page, click on a pending request. You will be able to listen to the audio (or read the text) and submit a Peer Score (1-10) and written Comments. The request then moves to the 'Completed' status.
